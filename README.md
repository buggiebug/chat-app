# Chat App

This is a real-time chat application built using MERN & WebSockets.
You can access the live version of the app at the following URL:

🚀 [Live App](https://gap-sap.netlify.app/) - Explore the app now!

The application works as follows:

- The frontend is built using React.js and is hosted on Netlify.
- The backend is built using Node Js & Express Js & is deployed on Render.
- The database is a MongoDB Atlas database.
- The application uses WebSockets to establish real-time communication between the client and the server.

When running the application on a local machine, the following steps need to be taken:

- Run `npm install` in the root directory to install all the dependencies.
- Run `npm start` in the root directory to start the server.
- Open a new terminal window and run `npm start` in the `client` directory to start the client.
- The application should now be accessible at `http://localhost:3000` in the browser.
